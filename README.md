## Français

Bienvenue sur le dépôt officiel de **SunoApp**, une application de lecteur/gestionnaire de musique créée par Flora Cherry.

### À propos

SunoApp est un projet innovant conçu pour offrir une **expérience fluide et intuitive** de gestion et de lecture musicale. Que vous soyez un créateur ou un mélomane, SunoApp vous permet de gérer vos créations et vos playlists en toute simplicité.

### ✨ Fonctionnalités

#### 🎨 Interface intuitive
Gestion ergonomique et claire de tes créations musicales avec un design moderne et accessible.

![Interface principale](https://github.com/user-attachments/assets/a4acbbc2-97da-4242-b0ef-6322245937b6)

#### ▶️ Contrôle de lecture avancé
Contrôlez votre musique avec des commandes essentielles :
- **Play** - Démarrer la lecture
- **Pause** - Mettre en pause
- **Stop** - Arrêter complètement
- **Précédent** - Piste précédente
- **Suivant** - Piste suivante

![Contrôles de lecture](https://github.com/user-attachments/assets/e8e3bae5-fd6b-4926-973e-65f82ee32d2a)

#### 🎯 Design personnalisé
- Icônes uniques et modernes
- Interface responsive et adaptée à tous les écrans
- Thème épuré et professionnel

### 🚀 Installation

#### Prérequis
- Node.js (v14.0 ou supérieur)
- npm ou yarn

#### Étapes d'installation

1. Clonez le dépôt :
```bash
git clone https://github.com/HanaCherry/SunoApp.git
cd SunoApp
```

2. Installez les dépendances :
```bash
npm install
npm install electron-builder --save-dev
```

3. Lancez l'application :
```bash
npm start
```

L'application s'ouvrira automatiquement sur `http://localhost:3000`
