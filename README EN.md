SunoApp 🍒
About
SunoApp is a music player application designed for a fluid and intuitive user experience.

Features
Intuitive Interface: Easy navigation for managing your creations.

Playback Control: Simple controls including Play, Pause, Stop, Previous, and Next.

Custom Design: Featuring unique icons and a personalized look.

Installation
Currently in development.
