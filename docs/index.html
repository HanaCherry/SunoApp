Installation Windows

Téléchargez l’installateur de la dernière release. Windows SmartScreen peut avertir : l’app n’a pas encore de certificat commercial.

  1. 1
    Ouvrez la page Releases du dépôt.
  2. 2
    Téléchargez l’installateur .exe de la dernière version.
  3. 3
    Lancez l’installateur.
  4. 4
    Ouvrez SunoApp et connectez-vous à Suno comme d’habitude.

Développement

Node.js 22 ou plus.

git clone https://github.com/HanaCherry/SunoApp.git
cd SunoApp
npm install
npm start

Projet indépendant

SunoApp n’est ni affilié ni approuvé par Suno. Marque et service appartiennent à leurs détenteurs.
